# Personal Portfolio Website - Vinayak Singh

A responsive personal portfolio built with **HTML5 and CSS3 only** (no JavaScript, frameworks, or backend) for the EWB Courses HTML & CSS Internship.

## Features
- Semantic structure: `header`, `nav`, `main`, `section`, `article`, `footer`
- All required sections: Header/Nav, Home, About, Skills, Projects, Contact, Footer
- 11 skills (5 shown as progress bars) and 3 project cards
- CSS variables, Flexbox and Grid, tablet and mobile media queries
- Automatic dark mode that follows the device setting
- Reading-progress bar and back-to-top button (CSS scroll animations)
- Skip-to-content link, visible keyboard focus, reduced-motion support, print styles
- Contact form is a **visual demo only**: nothing is stored, and sending opens the visitor's email app

## Files
- `index.html`: page content
- `style.css`: all styling
- `screenshots/`: desktop and mobile screenshots

## Run locally
Open `index.html` in any browser.
